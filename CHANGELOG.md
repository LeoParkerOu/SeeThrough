# Changelog

## 0.4.0-beta.1

First public SeeThrough beta, prepared from the local component-factory prototype.

- Explore project responsibilities as nested 3D components.
- Ask the original DSH Agent about selected components; let the graph Agent focus and highlight relevant parts.
- Preserve saved graphs and explicit project selection.
- Include question-view support, component context menus, relationship exploration and view restoration.
- Package standalone build sources, pinned development dependencies and an allowlisted precompiled installer.
- Rename the public package and UI to SeeThrough; retain compatible internal routes and local graph storage.

Compatibility target: DSH 0.2.1-rc.3, macOS. Beta limitations include bounded small-project analysis, model-generated semantic errors and unverified compatibility with other host versions.
